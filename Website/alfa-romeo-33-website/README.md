# Alfa Romeo 33 Stradale — One Page

A one-page website about the Alfa Romeo 33 Stradale. Design and coded by Zijian.

Built with **Vite + React + Three.js** (`@react-three/fiber` / `drei`).

## Scripts

```bash
npm install
npm run dev      # local dev server (http://localhost:3000)
npm run build    # production build → dist/
npm run preview  # preview production build
```

## Deploy

Static output is in `dist/`. On Vercel, set:

- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Root Directory:** `Website/alfa-romeo-33-website` (if deploying from monorepo root)

## Notes

- 3D models live under `public/carModel/`
- Images/fonts under `src/`
